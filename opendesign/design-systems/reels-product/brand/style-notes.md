# Style notes

## Color

- `--bg-1` canvas, `--bg-2` elevated chrome, `--bg-3` cards.
- Amber `--accent-1` for primary CTA, focus rings, brand period.
- Teal = healthy system; danger red sparingly.
- Borders at 8% white; avoid heavy outlines.

## Type

- Fraunces for logo and section titles; Instrument Sans for UI.
- Body ~15px / 1.5. Titles slightly tight tracking.

## Spacing & radius

- 8px-based gaps; page padding `clamp(16px, 2vw, 32px)`.
- Radius 10px cards, 16px large media frames; pills only on search.

## Motion

- Short transitions (0.15–0.2s) on border/shadow/focus.
- Prefer one high-impact moment over many micro-motions.

## Patterns observed

- Sticky translucent header with blur.
- Horizontal media rows + infinite library grid.
- Watch: player column + related sidebar.
- Modals for create clip, captions, cleanup, publish, webcam.
- FAB for gallery on home; system dock for health.
